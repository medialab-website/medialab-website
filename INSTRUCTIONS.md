# Tri-Cities MediaLab Website Instructions

This document provides simple instructions for updating your website without writing code.

---

## 1. Where to Paste Form Embed Codes

You will find a placeholder in the HTML where you need to copy and paste the snippet provided by your service.

**Aryeo (Real Estate)**
- **File:** `real-estate.html`
- **Location:** Open the file, press Command+F (Find), and search for `[Aryeo Embed Code Goes Here]`.
- Replace that entire line with the HTML snippet Aryeo gives you.

**HoneyBook (Weddings)**
- **File:** `weddings.html`
- **Location:** Search for `[HoneyBook Embed Code Goes Here]`.
- Replace that line with your HoneyBook widget snippet.

**Google Forms (Creative)**
- **File:** `creative.html`
- **Location:** Search for `[Google Form Embed Goes Here]`.
- Replace that line with the `iframe` code generated by Google Forms.

---

## 2. Where to Update Videos

We are using a highly optimized "Lite" YouTube embed. You do not need to paste heavy iframe code. You only need the **YouTube Video ID**.

For example, if the video URL is: `https://youtube.com/watch?v=dQw4w9WgXcQ`
The Video ID is: **`dQw4w9WgXcQ`**

**How to add a video:**
1. Open the HTML page (e.g., `weddings.html` or `portfolio/creative.html`).
2. Search for `data-id="YOUR_YOUTUBE_ID..."`.
3. Replace the placeholder with your actual Video ID. For example: `data-id="dQw4w9WgXcQ"`.

---

## 3. How to Deploy to Netlify

Because this site is 100% static HTML, CSS, and JS, deployment takes less than 3 minutes.

1. **Create a GitHub Repository:** Drag and drop this folder (`TCML_Website`) into a new GitHub repository (or use GitHub Desktop).
2. **Log into Netlify:** Go to [netlify.com](https://netlify.com) and sign in.
3. **Add New Site:** Click "Add new site" > "Import an existing project".
4. **Select GitHub:** Choose your repository.
5. **Deploy:** Leave build command and publish directory completely blank. Click "Deploy Site".
6. **Set Domain:** Go to "Domain Management" in Netlify and connect `medialab.fyi`. Netlify will automatically handle the SSL/HTTPS certificate for free.
